# PaperOrchestra 订阅版 Skill 首版规格草案

状态：供讨论。目标宿主暂定为使用订阅登录的本地 Codex。目标用户已有实验材料，希望用同一份稿件完成写作、核查和后续修改。首版建议先交付一节能继续编辑的实验结果，并把它放回已有 LaTeX 稿件。完整论文生成保留为产品方向。

首个可用入口为 [paper-writing](../SKILL.md)。[CVPR 2025 示例](../examples/cvpr2025/HANDOFF.md)已从合成记录写入实验节并编译，且通过[独立会话续稿验收](validation.md#cvpr-handoff)。

## 作者怎样使用

1. 作者给出当前稿或会议模板、实验记录和可用文献，提出“写实验结果”或“核对这个指标”。Skill 查明当前采用稿、材料来源和可运行的构建入口。找不到可靠数据时，保留待补项。
2. 会话起草目标段落，将数字关联到文件、行或样本 ID。统计图复用用户现有的绘图数据、脚本和样式。外部资料进入参考文献前，要分别确认文献身份和对论点的支持程度；只有题录或摘要时记录证据范围。
3. 作者可以直接修改源稿。下次会话按项目交接说明定位采用稿，复核受影响的文字、表格和图，给出局部差异及构建结果。作者稿与新请求冲突时保留作者版本，列出需要决定的句子。

## 建议的入口与交接

一个用户入口，内部按材料与证据、写作与修订、图表与交付组织阶段。使用者可以只调用其中一个阶段；各阶段交换普通文件。多入口方案适合某个阶段形成独立用户需求后再评估，例如用户经常只要求引文核查。

| 交接信息 | 谁提供或维护 | 接手会话要能判断什么 |
|---|---|---|
| 当前稿及编译入口 | 作者指定采用稿，Skill 在交接说明里记录相对路径 | 当前 TeX、历史稿、图和引用分别在哪里，如何重建 |
| 关键主张和证据 | 写作会话按指标登记观测对象、证据位置、单位、分母与样本范围 | 同名或同值的观测能否区分，派生数字怎样复算 |
| 图的重建信息 | 制图阶段记录图文件、数据、脚本、对应正文及运行依赖 | 怎样更新图形、图注和论文实际嵌入的版本；仅有位图时标出缺失图源 |
| 本轮状态 | 当前编辑者随交付更新 | 哪些修改已采用、哪项还缺证据、构建成功的是哪个版本 |

沿用已有项目文件名和相对路径。交接说明可引用作者已有的 README、构建脚本和表格，避免重复维护。附 PDF 的前提是本轮从采用稿构建并核验过；缺工具时仍可交付源码并注明具体缺项。

## 费用与依赖

大纲、写作和审阅使用当前订阅会话；基础写作路径不要求单独付费模型 Key。联网检索、图像生成或跨模型审阅按宿主工具及可用权限决定；带本地文献和原始数据的路径应能单独使用。初版不以另装 ARS 或 Zotero 为前提。LaTeX 工具链、字体和绘图库是可核查的本地依赖。首次运行需留下实际成功的构建命令及资源条件。订阅额度消耗尚无可归因的同条件测量。

## 首版验收

| 用户请求 | 可观察的通过条件 | 现有证据 |
|---|---|---|
| 换会话，更正一个实验值 | 找对作者稿，按原始时间戳复算，保留作者手改，更新 PDF 可读取 | [CVPR 合成样例续稿](validation.md#cvpr-handoff) |
| 跨节更正同一指标 | 摘要、表格、派生差值和阈值结论一致，保留另一个同值指标 | [CVPR 合成样例续稿](validation.md#cvpr-handoff) |
| 更正进入统计图的数据 | 来源数据可回查，正文数值和差值、图注、图形长度及数值标签一致；重新编译后的 PDF 内嵌正确版本 | [CVPR 合成样例续稿](validation.md#cvpr-handoff) |
| 从用户实验材料起草并补入既有稿件 | 一份真实模板能重建，作者可修改，书目可解析，抽查引文有依据；在独立安装中复现 | [CVPR 2025 合成样例](validation.md#cvpr-first-build)在 Windows 干净副本编译通过 |

## 首版仍需决定的范围

建议先支持已有 LaTeX 稿件或模板、用户提供的文献、可重建的统计图。自动搜索、自动概念图、多轮模型审稿和从零生成整篇论文分别增加外部工具与用量，适合后续按需求选择。上游 Python 的大纲和文献模块直接调用模型 API，交付 Skill 时需要让会话接管这些步骤；原模板和确定性的本地编译逻辑可单独评估复用。公开分发前核对实际携带的模板、脚本和第三方文件许可。

首个示例在 Windows 上使用 CVPR 2025 模板，已用当前订阅会话完成写作、引文核对、图表重建与编译。其他平台、会议模板和更长稿件仍待验证。P1 需求访谈及 P5 整体质量与用量对比暂缓。
