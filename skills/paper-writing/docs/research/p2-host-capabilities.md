# P2 · 订阅环境能力

2026-11-19 调研快照，依据 PaperOrchestra 的 `d9bae99`。文中的仓库、CLI 和环境检查指调研当时的上游与本机环境。后续实测见[验收汇总](../validation.md)。

**PaperOrchestra 可以改造成无需单独模型 API Key 的交互式 Codex Skill。** 让订阅登录后的 Codex 会话负责提纲、写作、综述和修订，复用原仓库的提示词、LaTeX 模板和引用产物。原 CLI 的模型调用需要替换。全文、PDF 视觉审阅、自动制图和编译各有独立的权限或工具前提，可以按实际环境降级。[Codex 认证](https://learn.chatgpt.com/docs/auth) · [Skill 官方文档](https://learn.chatgpt.com/docs/build-skills)

仓库证据基于 `main` 的 `d9bae997`。CLI 按 `--use_plotting` 选择是否运行绘图分支，两条路径都经过提纲、文献综述、章节写作和内容修订。提纲、文献发现和修订多处直接调用 Gemini。即使给支持 OpenAI 的章节写作传入模型名，该分支仍使用 `OPENAI_API_KEY` 调用 Chat Completions。关闭绘图只跳过绘图分支。[CLI 入口](https://github.com/google-research/paper-orchestra/blob/d9bae997e793a015ed38bb1605be9eb58c00284f/paper_writing_cli.py#L141) · [提纲调用](https://github.com/google-research/paper-orchestra/blob/d9bae997e793a015ed38bb1605be9eb58c00284f/methods/agents/outline_agent.py#L51) · [模型适配器](https://github.com/google-research/paper-orchestra/blob/d9bae997e793a015ed38bb1605be9eb58c00284f/utils/llm_backend_utils.py#L105) · [OpenAI 客户端](https://github.com/google-research/paper-orchestra/blob/d9bae997e793a015ed38bb1605be9eb58c00284f/utils/openai_utils.py#L35) · [Gemini 客户端](https://github.com/google-research/paper-orchestra/blob/d9bae997e793a015ed38bb1605be9eb58c00284f/utils/gemini_utils.py#L36)
